How to Import

        

            

                1
                
Tap Download v2ray_adblock.json above (or Copy to clipboard).

            

            

                2
                
Open v2rayNG or v2rayTun and go to your server / profile settings, then find the Routing / Routing Settings section.

            

            

                3
                
Enable Sniffing first: in v2rayNG go to the server's edit screen → Sniffing toggle → on (destination override for HTTP/TLS); in v2rayTun go to Settings → Sniff / Sniffing → enable it. Domain-based rules will not match anything without this.

            

            

                4
                
v2rayNG: Settings → Routing Settings → tap the "+" or import icon → choose Import from file and select the downloaded JSON (or paste it if using "Import from clipboard").

            

            

                5
                
v2rayTun: Settings → Route Rule / Routing → Import → pick the downloaded file, or paste the copied JSON into the custom routing rules editor.

            

            

                6
                
Save, then make sure the outbound tag named proxy (or whatever you use) matches your actual proxy outbound, and that a block outbound exists so the adblock rule can drop matched domains.

            

        

    


    
    

        
Frequently Asked Questions

        

            

                
What format does this hosts file need to be?

                
Standard hosts format: one entry per line, e.g. 0.0.0.0 ads.example.com. Lines starting with # are comments, blank lines and localhost entries are ignored automatically.

            

            

                
Why did fetching the URL fail?

                
Some hosting providers block cross-origin requests (CORS) from browsers. raw.githubusercontent.com links usually work; if yours doesn't, download the file yourself and use the "From File" tab.

            

            

                
What do the base rules do?

                
They block outbound UDP/443 (QUIC, to force fallback and avoid Google/Chrome bypassing your proxy), send private/LAN IPs and domains direct instead of through the proxy, and route everything else to the proxy outbound before the adblock rule blocks matched domains.

            

            

                
Is my data uploaded anywhere?

                
No. The hosts file is fetched or read directly by your browser, parsed locally, and the JSON is generated entirely client-side. Nothing is sent to any server run by this page.

            

            

                
Why do I need to enable "Sniffing"?

                
Domain-matching rules (like this adblock ruleset) can only match a domain. But most apps on your phone connect using a raw destination IP, not a hostname — the DNS lookup happened earlier and V2Ray/Xray only sees an IP:port. Sniffing makes the core peek at the TLS SNI or HTTP Host header of the connection to recover the real domain before routing decides where to send it. Without Sniffing enabled, the core has no domain to compare against your rules, so every "domain" rule (including this adblock list and any geosite rules) is silently skipped and traffic falls through to whatever rule matches by IP/port instead — meaning ads won't be blocked and the rule set effectively does nothing.
