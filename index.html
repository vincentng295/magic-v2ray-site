System-Wide Coverage
Phủ toàn bộ thiết bị
Every app on your phone goes through the proxy automatically — no extra setup per app. Devices connected via hotspot are covered too.
Mọi ứng dụng trên điện thoại đều đi qua proxy tự động — không cần cài thêm gì. Thiết bị kết nối hotspot cũng được bảo vệ theo.
Server Manager
Quản lý máy chủ
Paste a subscription link and your server list updates instantly. Duplicate servers are detected and removed automatically.
Dán link subscription vào là danh sách máy chủ tự cập nhật. Server trùng lặp được tự động phát hiện và loại bỏ.
Powered by Xray Core
Chạy trên nhân Xray
Just paste your server link — Magic V2Ray converts it into a working config automatically. Supports every major proxy format.
Chỉ cần dán link server — Magic V2Ray tự chuyển thành cấu hình hoạt động được. Hỗ trợ mọi định dạng proxy phổ biến.
Auto Network Switching
Tự chuyển mạng
Switches seamlessly between Wi-Fi and mobile data without dropping your proxy connection. Hotspot toggling is handled automatically too.
Chuyển liền mạch giữa Wi-Fi và dữ liệu di động mà không mất kết nối proxy. Bật tắt hotspot cũng được xử lý tự động.
Safe & Hidden VPN
An toàn & VPN ẩn thân
Operates seamlessly at the kernel level, completely invisible to the OS and aggressive system task killers. Enjoy rock-solid privacy with military-grade encryption that never drops or leaks your real IP.
Hoạt động mượt mà ở cấp độ nhân (Kernel), hoàn toàn ẩn mình trước hệ điều hành và các trình dọn RAM hệ thống. Tận hưởng sự riêng tư tuyệt đối với mã hóa cấp quân đội, không lo gián đoạn hay rò rỉ IP thật.
Clean Web UI
Giao diện Web gọn gàng
A clean, modern control panel that opens right in your browser. Available in both English and Vietnamese.
Trang quản lý hiện đại mở ngay trong trình duyệt. Hỗ trợ cả Tiếng Anh và Tiếng Việt.

Getting Started
Bắt đầu sử dụng

Install in 3 steps

Cài đặt trong 3 bước

1
Download the latest .zip release from the GitHub releases page.
Tải xuống bản release .zip mới nhất từ trang GitHub releases.
2
Flash the module via Magisk, KernelSU or APatch manager, then reboot your device.
Flash module qua ứng dụng Magisk, KernelSU hoặc APatch, sau đó khởi động lại thiết bị.
3
Open the web UI via the Action button in your Magisk / KernelSU / APatch app to start managing your proxies.
Mở giao diện web bằng nút Action trong ứng dụng Magisk / KernelSU / APatch để bắt đầu quản lý proxy.
