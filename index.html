An Android app that routes your apps through Xray-core. Install it like any other app and run it without root, or unlock the kernel-level daemon if your device is rooted.

Ứng dụng Android đưa ứng dụng trên máy đi qua Xray-core. Cài như app bình thường và chạy không cần root, hoặc mở khóa daemon cấp nhân nếu máy đã root.

Core Features
Tính năng chính

Everything you need, nothing you don't

Đủ tính năng, không rườm rà

One app to manage your servers, route your traffic and share the connection.

Một ứng dụng để quản lý máy chủ, định tuyến lưu lượng và chia sẻ kết nối.

Two modes, one app
Hai chế độ, một ứng dụng
Run in Root mode for a kernel-level daemon, or in Non-Root mode through Android's VpnService. Same UI and same Xray core either way.
Chạy Chế độ Root với daemon cấp nhân, hoặc Chế độ Non-Root qua VpnService của Android. Cùng giao diện, cùng nhân Xray.
Root daemon, no VPN slot
Daemon root, không chiếm VPN
On rooted devices Xray runs as a system daemon that the low-memory killer leaves alone. It does not use the Android VPN slot, so there is no key icon in the status bar and no clash with per-app VPNs.
Trên máy đã root, Xray chạy như daemon hệ thống mà trình dọn bộ nhớ không đụng tới. Không chiếm slot VPN của Android nên không có biểu tượng chìa khóa và không xung đột với VPN theo ứng dụng.
System-wide coverage
Phủ toàn bộ thiết bị
Apps go through the proxy automatically, with no per-app setup. Root mode intercepts at the Netfilter layer, which also reaches system UIDs that a normal VPN cannot. You can exclude individual apps.
Ứng dụng tự động đi qua proxy, không cần cài riêng từng app. Chế độ Root chặn ở tầng Netfilter nên cả UID hệ thống mà VPN thường không với tới cũng được phủ. Có thể loại trừ từng ứng dụng.
Server manager
Quản lý máy chủ
Paste subscription URLs, raw configs or mixed text and the servers are imported. Group them into categories and refresh subscriptions with one tap.
Dán link subscription, cấu hình thô hoặc văn bản hỗn hợp là máy chủ được nhập vào. Gom vào danh mục và cập nhật subscription chỉ với một chạm.
Powered by Xray-core
Chạy trên nhân Xray-core
Your server link is converted into a working Xray config automatically, for every protocol listed below.
Link máy chủ được tự động chuyển thành cấu hình Xray hoạt động được, cho mọi giao thức bên dưới.
Seamless network switching
Chuyển mạng liền mạch
In Root mode the service listens to kernel network events, so Wi-Fi and mobile data handovers reconnect right away.
Ở chế độ Root, dịch vụ lắng nghe sự kiện mạng của nhân nên khi đổi giữa Wi-Fi và dữ liệu di động sẽ kết nối lại ngay.
Hotspot sharing
Chia sẻ qua hotspot
Share the proxied connection with laptops, consoles and other phones over Wi-Fi hotspot or USB tethering, including IPv6. Without root, Shizuku enables this on Android 13+.
Chia sẻ kết nối đã qua proxy cho laptop, máy console và điện thoại khác qua hotspot Wi-Fi hoặc USB tethering, gồm cả IPv6. Không root thì dùng Shizuku (Android 13+).
Quick tile and clean UI
Ô cài đặt nhanh và giao diện gọn
Toggle the proxy from the Quick Settings tile (long-press opens the app). The built-in control panel is available in English and Vietnamese.
Bật tắt proxy ngay từ ô Cài đặt nhanh (nhấn giữ để mở app). Bảng điều khiển tích hợp có Tiếng Anh và Tiếng Việt.

Getting Started
Bắt đầu sử dụng

Install the app

Cài đặt ứng dụng

Non-RootNo root neededKhông cần root
1
Download magic_v2ray-*-arm64-v8a.apk (or -x86_64.apk) from the GitHub releases page and install it.
Tải magic_v2ray-*-arm64-v8a.apk (hoặc -x86_64.apk) từ trang GitHub releases rồi cài đặt.
2
Open the app, choose Non-Root (VpnService) Mode and grant the VPN permission.
Mở ứng dụng, chọn Chế độ Non-Root (VpnService) và cấp quyền VPN.
3
Import a server link or subscription, pick a server and start the connection.
Nhập link máy chủ hoặc subscription, chọn một máy chủ rồi bắt đầu kết nối.
RootMagisk / KernelSU / APatchMagisk / KernelSU / APatch
1
Option A, module + app: rename magic_v2ray-*.apk to .zip and flash it in Magisk / KernelSU / APatch (Modules → Install from storage). It installs the background module and the app.
Cách A, module + app: đổi tên magic_v2ray-*.apk thành .zip rồi flash trong Magisk / KernelSU / APatch (Modules → Install from storage). Việc này cài cả module chạy nền lẫn ứng dụng.
2
Option B, plain APK: install the APK, open it and grant root. The app sets up the daemon in /data/adb/modules/magic_v2ray and keeps your settings in /data/adb/magic_v2ray.
Cách B, cài APK thường: cài APK, mở app và cấp quyền root. Ứng dụng tự thiết lập daemon trong /data/adb/modules/magic_v2ray và giữ cài đặt của bạn ở /data/adb/magic_v2ray.
3
Reboot or just open the app, then start the connection. The module's Action button also launches the app, installing app.apk if it is missing.
Khởi động lại hoặc mở thẳng ứng dụng, rồi bắt đầu kết nối. Nút Action của module cũng mở ứng dụng và tự cài app.apk nếu chưa có.

Releases are built for arm64-v8a and x86_64. Each APK can also be renamed to .zip and used as a module installer.

Bản phát hành có cho arm64-v8a và x86_64. Mỗi APK cũng có thể đổi tên thành .zip để dùng làm bộ cài module.
